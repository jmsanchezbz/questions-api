# HOWTO
## Start php server
     php artisan serve

## Model
      php artisan make:model Name
      php artisan model:show Name

## Migrate
      php artisan migrate
      php artisan migrate:status
      php artisan migrate:rollback --step=1

## Routes
### Clear Route Cache
      php artisan route:clear

### Route List
      php artisan route:list
